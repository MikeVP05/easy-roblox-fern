## 🎛️ Config Presets And Switching

A multi-cheat without a config system is a toy. The preset model is what makes the
build usable.

**What a preset holds**

| **Group** | **Contents** |
| --- | --- |
| Visual | which overlays, colours, distances |
| Aim | bone, FOV, smoothing, gating |
| Cosmetic | active loadout |
| Identity | reset settings |
| Keybinds | per-module toggles |

**Four stock presets**

| **Preset** | **Character** |
| --- | --- |
| Minimal | overlay only |
| Standard | overlay + aim |
| Full | everything except cosmetics |
| Clean | everything off, for a normal session |

**Why "Clean" matters**

A preset with everything disabled is the most useful one in the list. It lets you play
a session that looks entirely normal without uninstalling anything, and it makes the
contrast obvious when you switch back.

**Custom profiles**

Save under your own names, as many as you want. Each is a separate file in the config
folder, so they can be copied between machines or backed up independently.

**Switching safely**

Load a profile before joining a lobby, not during one. Mid-match profile loads cause
the overlay to re-initialise, which is both visually obvious and unnecessary.

**Keybinds**

Bind one key per module rather than one key for everything. Being able to drop a
single module in a specific moment is more useful than an all-or-nothing panic key.
